# Lab 03 – Access Control & Secure File Operations

## Overview
This lab implements a Secure Healthcare File System using Python. It demonstrates Role-Based Access Control (RBAC), file permissions, secure prescription management, audit logging, and SHA-256 data integrity verification.

## User Roles
- Admin – Manage patient records and prescriptions.
- Doctor – Create and update prescriptions.
- Nurse – Read prescriptions (read-only).
- Patient – Access their own medical records and prescriptions.

## Security Features

### 1. Role-Based Access Control (RBAC)
- Role-based permissions
- Least privilege enforcement
- Unauthorized access prevention

### 2. Secure File Operations
- Create files
- Read files
- Write files
- Secure file deletion

### 3. Data Integrity Protection
- SHA-256 hashing
- Prescription integrity verification
- Unauthorized modification detection

### 4. Audit Logging
- User activity tracking
- File operation logs
- Access granted and denied events

### 5. Threat Analysis
- Insider threats
- Log tampering
- Privilege escalation
- Integrity metadata tampering
- Account lockout bypass

## Technologies Used
- Python 3
- SHA-256
- HMAC
- JSON
- Python Logging
- Role-Based Access Control
