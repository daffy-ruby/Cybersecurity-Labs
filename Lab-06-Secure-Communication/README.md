# Lab 06 – Secure Communication Using Public Key Cryptography

## Overview
This lab demonstrates secure communication between Hospital A and Hospital B using public-key cryptography.

## Technologies
- Python 3
- RSA-3072
- RSA-OAEP
- RSA-PSS
- AES-256-GCM
- SHA-256
- Diffie-Hellman
- PEM public keys

## Security Features
1. RSA key generation.
2. Public-key exchange.
3. Secure patient data encryption.
4. Digital signatures and verification.
5. AES session-key encryption.
6. Diffie-Hellman shared-secret establishment.
7. Message integrity verification.

## Project Files
Source code, lab assignment, final report and public-key files.

## Installation

```bash
pip install cryptography
```

## Execution

```bash
python lab6.py
```

## Security Note
Private keys, passwords and real patient information must never be uploaded to a public repository.

## Conclusion
This project demonstrates confidentiality, authentication, integrity and secure key exchange in a healthcare communication scenario.
