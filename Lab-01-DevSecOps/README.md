# Lab 01: DevSecOps Fundamentals & SDLC Security Integration

## Course
Cybersecurity Architecture, Design, and Secure Software Development

## Overview
This lab demonstrates how security can be integrated throughout the Software Development Life Cycle (SDLC).

## Tasks Completed

### Task 1 – DevSecOps Pipeline Mapping
- Security integration across SDLC stages
- Threat modelling and risk assessment
- CIA security principles

### Task 2 – Secure Data Storage
- Python implementation
- Fernet symmetric encryption
- SHA-256 integrity hashing
- JSON-based data storage

### Task 3 – Threat Analysis
- Encryption key exposure
- Insufficient input validation
- Unauthorized data modification
- Mitigation strategies

### Task 4 – Data Integrity Verification
- SHA-256 hash comparison
- Original vs tampered dataset
- Detection of modified records

## Technologies Used
- Python 3
- Cryptography (Fernet)
- SHA-256
- JSON
- GitHub

## Learning Outcomes
Understanding secure software development, data confidentiality, integrity, and threat mitigation.
